# 🏆 Dofus Rétro Speedrun

Un petit outil web pensé pour les joueurs de **Dofus Rétro** qui aiment pousser leurs donjons un peu trop loin. 😎

Lance le chrono, termine ton donjon et garde automatiquement une trace de tes performances.

## ⏱️ Fonctionnalités

- ⏱️ Chronomètre précis
- 🏆 Détection automatique des nouveaux records
- 📜 Historique complet des runs par donjon
- 📈 Graphique de progression
- 📊 Statistiques par donjon
- ⚡ Comparaison des temps avec le PB
- 📅 Suivi de l'activité et du nombre de runs
- 🗺️ Ajout et suppression de donjons
- 💾 Sauvegarde automatique des données dans le navigateur
- 📤 Export des données en JSON
- 📥 Import d'une sauvegarde JSON
- 📱 Compatible PC, tablette et téléphone

## 🎮 Comment ça marche ?

1. Sélectionne ton donjon.
2. Clique sur **START** au lancement du combat.
3. Fais ton run.
4. Clique sur **FINISH**.
5. Ton temps est automatiquement ajouté à l'historique.

Et si tu viens de battre ton PB...

# 🏆 NOUVEAU RECORD !

L'application calcule automatiquement ton amélioration par rapport à ton ancien record.

## 💾 Où sont enregistrés mes records ?

Les données sont enregistrées **localement dans ton navigateur**.

Tu peux donc fermer Chrome et revenir plus tard : tes chronos seront toujours là.

⚠️ Les données sont propres à chaque navigateur/appareil.

Pense à utiliser **Exporter mes données** pour conserver une sauvegarde de tes records.

## 🌐 Utiliser l'application

👉 **https://adrienutile.github.io/Speedrun-timer-Dofus-retro/**

Aucune installation nécessaire.

Ouvre simplement le site depuis Chrome, Firefox, Edge ou ton navigateur mobile.
